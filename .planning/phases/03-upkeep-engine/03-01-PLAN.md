| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Elevation of Privilege | deadline_config writes via API | mitigate | createRule=ADMIN, updateRule=ADMIN — only head_admin can change scheduler config |
| T-03-02 | Tampering | submission_history forged by clients | mitigate | createRule=null on submission_history — only JSVM scheduler context can write |
| T-03-03 | Information Disclosure | Faction A reading Faction B submissions via direct API | accept | Phase 4 enforces faction scoping for portal users; Phase 3 staff are trusted (STAFF role only) |
| T-03-04 | Denial of Service | Massive submission spam fills DB | accept | High-trust 3-6 person team; PB request throttling sufficient |
| T-03-05 | Tampering | job_run_log forged by clients to mask scheduler failure | mitigate | createRule=null on job_run_log — only JSVM scheduler context can write |
