Zod schema: type (z.enum with all 6 DIPLO_TYPES), faction_a (string min 1), faction_b (string min 1), terms (optional string), start_date (string min 1), custom_name (optional string).
In action: if faction_a === faction_b → fail(400, 'Factions must be different'). If type === 'Custom' && !custom_name → fail(400, 'Custom name required'). Creates diplomacy record with status: 'active'.

`endAgreement` action:
Zod validates id (string min 1), end_date (string min 1), notes (optional). Updates diplomacy record: status='ended', end_date. No role gate beyond staff (staff can end agreements).
