<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Developer machine → version control | .env file must never be committed; .gitignore is the control |
| Build environment → runtime | PUBLIC_POCKETBASE_URL used at build time must not expose secrets |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Information Disclosure | .env file | mitigate | .gitignore must contain `.env` on its own line; .env.example documents structure without real values |
| T-01-02 | Information Disclosure | PUBLIC_POCKETBASE_URL in build env | accept | This is an intentionally public URL (the PocketBase public endpoint); no secrets are embedded in the build artifact |
| T-01-03 | Tampering | adapter-node build output | accept | Build artifact is internal to the deployment container; no external write access |
</threat_model>
